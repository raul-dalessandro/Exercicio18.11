Filas

1) Gerenciamento de fila de atendimento hospitalar

No hospital "Só Falta Você", você foi contratado para gerenciar a ordem de atendimento do pronto-socorro. 
A ordem de atendimento segue a seguinte regra: para cada dois pacientes da fila prioritária, um paciente da fila normal deve ser atendido.

Desenvolva um programa que gerencie as filas utilizando senhas alfanuméricas, seguindo as seguintes regras:
- A fila normal deve utilizar senhas iniciadas com a letra N.
- A fila prioritária deve utilizar senhas iniciadas com a letra P.
- O usuário deve poder escolher a senha que deseja retirar, de acordo com a fila correspondente.
- O programa deve possuir uma função para exibir a próxima senha da sequência de atendimento, respeitando a regra de prioridade.
